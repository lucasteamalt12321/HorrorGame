## О проекте

3D-хоррор от первого лица. Игрок — тестировщик видеоигр, тестирующий вложенную 2D-игру. Центральная механика: поиск и документирование багов внутри игры-в-игре, с постепенным нарастанием мета-хоррора.

Стек: Godot 4.7, GDScript, GL Compatibility renderer, Jolt Physics.
