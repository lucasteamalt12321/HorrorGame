# Project Brief — HorrorGame

## Цель проекта

Создать цельный 3D-хоррор от первого лица на Godot 4.x: игрок — тестировщик видеоигр, тестирующий вложенную 2D-пиксельную игру. Центральный игровой цикл — поиск и документирование багов, отправка отчётов, получение новых заданий и постепенное раскрытие мета-хоррора (баги начинают нарушать границу между 2D-игрой и реальностью).

Главный принцип: начало выглядит как обычная работа тестировщика; хоррор нарастает постепенно.

## Рамки проекта

- Движок: Godot 4.7, GL Compatibility renderer, Jolt Physics.
- Язык: GDScript. Без сторонних плагинов без необходимости.
- Игра должна открываться и редактироваться обычным Godot Editor.
- Основная игра — 3D; тестируемая игра — 2D pixel-art (living inside monitor SubViewport).
- Проект развивается фазами по ТЗ (PHASE 0..23).

## Критерий готовности (итоговый)

Игрок может пройти полный цикл: запуск → офис → задание → компьютер → 2D-игра → уровень → баг → фото → офис → отчёт → новое задание → сюжет → хоррор-события → финал → концовка. Прогресс сохраняется, системы не конфликтуют, финал достижим без ручного вмешательства.
